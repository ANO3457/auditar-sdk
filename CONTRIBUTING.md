# Contributing to auditar-sdk

Thanks for your interest in contributing.

## Good first issues

We label issues with `good-first-issue`, `help-wanted`, and `documentation`.
If you're new to the repo, start with a `good-first-issue`.

## Setup

```bash
git clone https://github.com/Pulvan/auditar-sdk.git
cd auditar-sdk
uv sync
uv run pytest
```

## Style

- Keep changes minimal and focused.
- Add tests for behavior changes.
- Update README if you add public API surface.
